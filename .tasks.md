## Tasks

This is tasks file using xcfile.dev for common tasks.

### build:plugins

Build all example plugins.

interactive: true

```bash
for plugins in google-search brave-search bing-search duckduckgo-search perplexity-search; do
  echo "Building plugin: $plugins"
  cargo build --release --target wasm32-wasip1 --manifest-path "examples/plugins/$plugins/Cargo.toml"
done
```

### build:images

Build docker images of plugins

interactive: true

```bash
cd examples/plugins
for plugins in google-search brave-search bing-search duckduckgo-search perplexity-search; do
  echo "Building image for plugin: $plugins"
  cd $plugins
  docker build -t ghcr.io/sevir/hyper-mcp/plugin-$plugins:latest .
  cd ..
done
```

### push:images

Push docker images of plugins

interactive: true

```bash
for plugins in google-search brave-search bing-search duckduckgo-search perplexity-search; do
  echo "Pushing image for plugin: $plugins"
  docker push ghcr.io/sevir/hyper-mcp/plugin-$plugins:latest
  # create and push multi-arch manifest (expects per-arch images with -linux-amd64 and -linux-arm64 tags)
  MANIFEST_TAG="ghcr.io/sevir/hyper-mcp/plugin-$plugins:latest"

  echo "Creating manifest list: $MANIFEST_TAG"
  if docker manifest create "$MANIFEST_TAG" 2>/dev/null; then
    docker manifest annotate "$MANIFEST_TAG" --os linux --arch amd64 || true
    docker manifest push "$MANIFEST_TAG"
  else
    echo "Could not create multi-arch manifest for $plugins; attempting single-image manifest"
    docker manifest create "$MANIFEST_TAG" "ghcr.io/sevir/hyper-mcp/plugin-$plugins:latest" && docker manifest push "$MANIFEST_TAG" || echo "Skipping manifest for $plugins"
  fi
done

```
