# New feature development plan

This is a plan for developing a new feature in the hyper-mcp project, adding and developing new plugins.

In the path `examples/plugins/perplexity-search` there is an example of a plugin in Rust that can be used as a starting point. In the README.md in the root path of the project there are instructions on how to build with a Dockerfile, please copy the same structure and files adapting to the required task. The readme contains tasks for building and pushing the docker image to GitHub Container Registry, copying and adapting those tasks for the new plugins is recommended.

- [x] Implement a new plugin in Rust for search in Google Search using Custom Search JSON API. Search in internet and Context7 for libraries and how to do it. The folder `examples/plugins/google-search` contains the scaffold of the plugin. Also write a README.md file with instructions on how to use it into this path.
- [x] Implement a new plugin in Rust for search using Bing Search API. The folder `examples/plugins/bing-search` contains the scaffold of the plugin. Also write a README.md file with instructions on how to use it into this path.
- [x] Implement a new plugin in Rust for search using Brave Search API, the OpenAI specs is in https://github.com/automation-ai-labs/mcp-link/raw/refs/heads/main/examples/brave.yaml. The folder `examples/plugins/brave-search` contains the scaffold of the plugin. Also write a README.md file with instructions on how to use it into this path.
- [x] Implement a new plugin in Rust for search using DuckDuckGo Search API, the OpenAI specs is in https://github.com/automation-ai-labs/mcp-link/raw/refs/heads/main/examples/duckduckgo.yaml. The folder `examples/plugins/duckduckgo-search` contains the scaffold of the plugin. Also write a README.md file with instructions on how to use it into this path.
- [x] Implement a new plugin in Rust for search in Perplexity Search. Search in internet and Context7 for libraries and how to do it. The folder `examples/plugins/perplexity-search` contains the scaffold of the plugin. Also write a README.md file with instructions on how to use it into this path.
- [x] Implement a new plugin in Rust for working with YouTrack API. You have the OpenAPI specs in https://digio.youtrack.cloud/api/openapi.json add a config for base url like https://digio.youtrack.cloud/api and the env var for the authorization token. Add the new plugin in the path `examples/plugins/youtrack` and write a README.md file with instructions on how to use it into this path and the dockerfile to build and push the image to GitHub Container Registry. I want to add the same tools like the github repo https://github.com/Digio-Campus/Youtrack-mcp that implements in python how to get the full info of tasks of a agile board, get info of a task by issue id, I want to use the same description of the tools and paramenters. Also implement another tools for create and update issues using the project name, get the custom fields before for filling the fields correctly, the tools for create and update must receive no field restricted json object because the custom fields are dynamic and can change from one youtrack project to another.
- [x] Implement a new plugin in Rust for working with Logseq API. Search with Google how works and what are the endpoints. Create folder `examples/plugins/logseq` with the code of the plugin. Also write a README.md file with instructions on how to use it into this path, adapting the tasks of readme for build image and upload to github container registry. Use apikey and base url as env vars for configuration. Use the Gist https://gist.github.com/digiogithub/0608dc6132ea5a18ca5249c076d951a1 as reference for a code in Python using Logseq API and adapt to Rust creating a tool for search pages, get blocks of a page or subblocks of a block, or generate the full references and child blocks of a block recursively to get the full content of the references of a page or tagkeyword.
- [x] Implement a new plugin in Rust for working with Google Workspace and Google Docs, adapting in the plugin the same tools and functionality of this mcp server https://github.com/dev-ithitchhiker/mcp-google-docs and https://github.com/a-bonus/google-docs-mcp. Create folder `examples/plugins/gdrive` with the code of the plugin. Also write a README.md file with instructions on how to use it into this path, adapting the tasks of readme for build image and upload to github container registry. Uses OAuth2 access token passed as environment variable (GOOGLE_ACCESS_TOKEN) for authentication. **Note**: Due to OAuth2 complexity and WASM plugin limitations, this implementation uses pre-configured access tokens. Token refresh must be handled externally.
